# Website — Next Level Gaming & Esports Arena

Task 2 static website source. Open `index.html` in a browser; no build step is needed. The site includes Home, About Us, Experiences, seven individual offer pages, Calculate Fees, and Contact Us. Shared styling and interaction are in `styles.css`, `site.js`, `quote.js`, and `forms.js`.

The fee calculator supports multiple bookings, the scenario's 0%, 5%, 10%, and 15% discount tiers, and 15% VAT on the discounted subtotal. It labels the result as an estimate, not a formal invoice. Contact and booking forms validate fields and show local feedback. Confirm venue details before a live launch.

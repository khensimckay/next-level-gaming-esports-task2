# Mobile application — Next Level Gaming & Esports Arena

Task 2 Expo / React Native source. Install Node.js and dependencies, then run:

```sh
npm install
npx expo start
```

The app includes Home, About Us, Experiences overview, individual offer details, Calculate Fees, and Contact screens. The calculator applies the scenario booking discounts and 15% VAT on the discounted subtotal, and labels the result as an estimate rather than an invoice.

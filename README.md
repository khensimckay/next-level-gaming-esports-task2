# Task 2 — Next Level Gaming & Esports Arena

This repository contains the Task 2 website and mobile application source for the Next Level Gaming & Esports Arena scenario.

## Website

Source is in [`website/`](website/). Open `website/index.html` in a browser to view it locally. The site includes the home and about pages, experiences overview and offer details, fee calculator, and contact page. Shared styles and behavior are in `styles.css`, `site.js`, `quote.js`, and `forms.js`.

## Mobile application

Source is in [`mobile-app/`](mobile-app/). Install Node.js and dependencies, then run:

```sh
cd mobile-app
npm install
npx expo start
```

The app uses Expo and React Native. See [`mobile-app/README.md`](mobile-app/README.md) for details.
